# Itens

## Objetivo

Especificar todos os detalhes gerais sobre os itens presentes em Her-o-clock.

## Itens

- Os itens serão descritos futuramente.

## Classes de equipamento

- Todo equipamento pertence a uma das três classes abaixo.
- A classe do equipamento define como os atributos principais do personagem são convertidos em atributos secundários, conforme descrito em `attributes.md`.
- Cada classe é liberada por um atributo principal diferente, então a escolha do equipamento acompanha naturalmente a build do personagem.

### Equipamento leve

- Liberado por AGI.
- É a melhor classe para evasão e para velocidade de ataque.
- É a classe do personagem que sobrevive desviando dos ataques ao invés de absorvê-los.

### Equipamento mágico

- Liberado por SPE.
- É a melhor classe para redução de recarga.
- É a classe do personagem que vence usando habilidades com a maior frequência possível.
- Apesar do nome, todo equipamento mágico continua sendo tecnologia, assim como todo o resto do universo de Unia.

### Equipamento pesado

- Liberado por POW.
- É a melhor classe para armadura física e para resistência elemental.
- É a pior classe em evasão, velocidade de ataque e redução de recarga.
- É a classe do personagem que sobrevive absorvendo os ataques ao invés de desviá-los.
