# Game objects

## Objetivo

Esta pasta descreve o que é cada GameObject da Unity presente no projeto, servindo como indicação do que precisa ser montado ou conferido na interface do editor.

## Convenção

- Um arquivo por GameObject ou por conjunto de GameObjects diretamente relacionados.
- Utilize a nomenclatura `nome-do-game-object.md`.
- Cada arquivo deve deixar claro:
    - O que aquele GameObject representa e onde ele fica na hierarquia.
    - Quais componentes ele possui.
    - Quais valores são recomendados em cada componente.
    - Quais associações (referências, prefabs, assets) precisam estar preenchidas para o projeto rodar normalmente.
